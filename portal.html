How admin login stays secure

  1. Password is not written in public HTML/JS.
  2. Cloudflare stores only a SHA-256 hash as a Worker secret (ADMIN_PASSWORD_HASH).
  3. Successful login sets an HttpOnly, Secure, SameSite cookie for 12 hours.
  4. Lead APIs rate-limit abusive submissions.

To set or reset the password on your machine with Wrangler: printf 'YourNewPassword' | shasum -a 256 then npx wrangler secret put ADMIN_PASSWORD_HASH and npx wrangler secret put SESSION_SECRET.
