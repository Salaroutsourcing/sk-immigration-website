# Content distribution — YouTube, Reels & citations

Goal: earn brand mentions and AI Overview citations for money queries.

## Cadence (weekly)

1. Publish **1 long YouTube** (8–12 min) answering one intent page.
2. Cut **3 short clips** (Reels / TikTok / Shorts) from it.
3. Pin the matching site URL in description + pinned comment.
4. Ask 2 closed clients for a **Google review** (process quality only).

## Transcript rules (AI Overview friendly)

- Lead with a one-sentence direct answer.
- Cite official sources verbally (“check German mission / VFS / IRCC”).
- State “embassies decide; no fake guarantees.”
- End with NAP + WhatsApp + page URL.
